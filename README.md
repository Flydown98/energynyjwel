## 3. 이번 버전 핵심 변경

### 스테이지 자유 선택
1~5번을 순서대로 해금하지 않습니다. 처음부터 5개 모두 선택할 수 있습니다.
어떤 순서로 하든 별 5개를 모두 모으면 자동으로 기록/공유 화면으로 이동합니다.

### 다시 방문했을 때 완료화면 복귀
일반 웹에서는 브라우저에 게임 완료 상태와 참여코드/등록/공유 상태만 저장합니다.
이름과 전화번호는 localStorage에 저장하지 않습니다.

별 5개를 이미 완료했다면 첫 화면에 `별 5개 완료 · 기록/공유 화면으로` 버튼이 나타납니다.
Instagram 공유까지 완료했다면 `이미 참여를 완료했어요` 안내가 나타나며 기록 등록/공유 버튼이 잠겨 같은 브라우저의 중복 응모를 막습니다.

> 브라우저 저장소를 지우거나 다른 기기/브라우저를 사용한 경우까지 동일인을 완벽히 판별하는 기능은 아닙니다. 전화번호 기준 서버 중복검사까지 원할 경우 별도 로직을 추가할 수 있습니다.

### Instagram 공유 완료 기록
모바일 시스템 공유가 정상 완료되면:
- 브라우저에 `sharedAt` 저장
- Apps Script에 `markShare` 전송
- Google Sheet의 `공유상태 / 공유일시` 갱신
- 이후 같은 브라우저에서는 공유 버튼이 `Instagram 인증 완료`로 바뀌고 잠깁니다.

PC/공유 미지원 환경에서는 대체 창의 `공유를 완료했어요` 버튼으로 완료 상태를 표시할 수 있습니다.

## 4. KIOSK 모드
`kiosk.html`은 1080×1920 세로 화면을 기준으로 별도 CSS를 적용합니다.

키오스크 특징:
- 5개 스테이지 자유 선택
- 브라우저 localStorage에 게임 진행/참여코드/개인정보를 저장하지 않음
- 새로고침하면 항상 새 참여자로 시작
- 한 참여자가 등록을 마치면 `다음 참여자 시작하기` 버튼 표시
- 등록 후 20초가 지나도 자동으로 새 참여자 화면으로 초기화
- 상단 초기화 버튼으로 직원이 즉시 새 참여자 상태로 전환 가능
- Instagram 공유 영역은 키오스크에서는 숨김
- 각 참여자가 입력한 이름/전화번호는 등록 요청 후 입력칸에서 즉시 비움

중요: **키오스크 기기에 개인정보를 저장하지 않는다는 뜻**입니다. 참가자가 `기록 등록`을 누르면 이벤트 응모를 위해 이름/전화번호는 일반 참여와 동일하게 Google Sheet 서버에 저장됩니다.

## 5. Apps Script도 반드시 업데이트
이번 버전은 공유상태와 웹/키오스크 참여경로를 저장하므로 GitHub 파일만 교체하면 끝이 아닙니다.

Apps Script 프로젝트에서:

1. `apps-script/Code.gs` 내용으로 기존 `Code.gs` 교체
2. `apps-script/Admin.html` 내용으로 기존 `Admin.html` 교체
3. **배포 → 배포 관리 → 현재 웹 앱의 연필(수정) → 새 버전 → 배포**

기존 배포를 수정하면 `/exec` URL은 그대로 유지되므로 `config.js`를 다시 바꿀 필요가 없습니다.
기존에 관리자 비밀번호 설정이 끝난 프로젝트라면 `setupCampaign()`을 다시 실행할 필요는 없습니다.

기존 Google Sheet는 삭제하지 않습니다. 새 Code.gs가 기존 열 뒤에 자동으로 다음 3개 열을 추가합니다.

- 참여경로 (`web` / `kiosk`)
- 공유상태
- 공유일시

관리자 화면에도 참여경로와 공유완료 상태를 표시하도록 수정했습니다.

## 6. 키오스크 권장 설정
- 해상도: **1080 × 1920**
- 방향: 세로
- 브라우저 배율: 100%
- 전체화면/F11 또는 키오스크 브라우저 모드 권장
- 주소: `.../kiosk.html`

## 7. 교체 후 빠른 테스트

### 일반 웹
1. 첫 화면 → 스테이지 선택
2. 5번부터 먼저 눌러도 실행되는지 확인
3. 서로 다른 순서로 5개 완료
4. 마지막 스테이지가 무엇이든 자동으로 완료 화면 진입 확인
5. 새로고침 → 첫 화면에 완료/공유 바로가기 표시 확인
6. 기록 등록 → Instagram 인증
7. 다시 새로고침 → `이미 참여를 완료했어요` 확인

### 키오스크
1. `/kiosk.html` 접속
2. 1080×1920 세로 레이아웃 확인
3. 5개를 임의 순서로 완료
4. 이름/전화번호 등록
5. 입력값이 비워지고 `다음 참여자 시작하기` 표시 확인
6. 다음 참여자 버튼 → 별 0개 / 새 참여코드 확인
7. 새로고침 → 이전 참여자 진행상태가 남지 않는지 확인
